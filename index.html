— Capabilities

Four reusable signals, one quiet system.

Lumen Edge replaces brand color and heavy borders with light. Every component is assembled from the same four primitives — radial surface, hairline rim, horizon line, and Lumen focus glow — so the system reads as one material from button to panel.

Radial surfaces

An ellipse-at-bottom gradient gives every raised control the feel of light spilling from below. Reused as --surface-gradient.

surface gradient

Hairline rims

A 1px inset highlight at low alpha outlines every component, and strengthens to acknowledge hover and focus.

inset 1px 0.10 → 0.16

Horizon line

A 70%-wide gradient at the bottom edge fades from 0.2 to 1.0 — the universal signal for focus, activation, and depth.

width 70% lumen glow

Lumen focus

Keyboard focus is a cool-white outer ring — never blue, never tinted — so accessibility lives inside the system language.

1px ring 16px glow

Sub-chromatic palette

Hierarchy through luminance, not hue. Eight tokens cover canvas, surfaces, rims, text, and the Lumen highlight.

8 tokens 0 accents

One signature ease

Surfaces transition at cubic-bezier(.15, .83, .66, 1) at 1000ms — slow, weighted, intentional.

1000 ms single curve
